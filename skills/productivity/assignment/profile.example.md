# Profile

Copy this file to `profile.md` in the same folder and fill it in. The /assignment skill reads `profile.md` before anything else. `profile.md` is gitignored, so these details stay on your machine.

## Student

Your full name as it should appear on submissions, e.g. `Jordan Lee`.

## School folder

Where coursework is filed, e.g. `~/Documents/School/`. Each course has its own folder, ideally with a `Syllabus/` subfolder.

## Courses

| Code | Course folder |
|---|---|
| STAT 501 | Applied Statistics |

## Where work is filed

How each course folder organizes work, so new work lands beside its siblings. For example:

- Weekly work: `Weeks/Week NN — <topic>/<task folder>/`, with the topic taken from the syllabus schedule
- Homework: `Homework/Homework N/`

## File naming precedent

Names to fall back on when an assignment gives no pattern, e.g. `STAT501_HW3_Lee_Jordan.pdf`.

## Build precedents

Optional: paths to earlier build scripts worth reusing, such as an R Markdown render script.

## Preferences

Optional: standing decisions the skill should follow, e.g. how to handle course-wide policies.
